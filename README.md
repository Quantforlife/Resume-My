# Konark Barve — Portfolio V2

A minimalist black-and-white glassmorphism personal portfolio for Konark Barve.

## Includes

- About
- Experience
- Selected Projects
- Education
- Skills & Current Learning
- Contact
- Dark/light monochrome theme
- Project filtering
- Expandable experience
- Copy-email interaction
- Print / Save PDF
- Shree Sales Productions footer watermark
- Automatic GitHub Pages deployment

## GitHub Pages

For a personal site, create a repository named:

`YOUR-GITHUB-USERNAME.github.io`

Upload the **contents of this ZIP/repository**, not the ZIP file itself.

The deployment workflow is already included at:

`.github/workflows/pages.yml`

After pushing to `main`, go to:

**Repository → Settings → Pages → Source → GitHub Actions**

Then GitHub will publish the site at:

`https://YOUR-GITHUB-USERNAME.github.io/`

## Structure

- `index.html` — complete self-contained portfolio
- `.nojekyll` — static-site marker
- `.github/workflows/pages.yml` — Pages deployment
- `assets/` — reserved for future images/documents
